# Incident response

Detect via availability, authentication, queue and access anomalies. Contain affected credentials/routes; preserve minimal relevant logs and event chains with access controls. Assess affected personal data and processors. Rotate secrets and revoke sessions where needed. Have qualified counsel evaluate notification requirements and approved stakeholder notices; no statutory hour deadline is asserted here. Remediate root cause, test neighboring attack paths, restore safely and complete a postmortem. Owner/contact and escalation channels must be configured before real use.
